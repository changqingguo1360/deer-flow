## Source decisions

1. Typed public `execution = {preference: local|remote|auto, profile?: str}` is separate from internal kwargs. Default auto/no profile is Local. A permitted agent profile selects Fleet. Explicit remote without profile fails. Bound keyed resume remains authoritative; a conflicting explicit selection fails.
2. Frozen `FleetConfig.agent_bindings[profile]` holds explicit allowed user IDs, model/version, actual pinned image WorkerCompatibility, secret references and continuation budget. Validate profile/runtime equality. Client owner/backend/placement/token hints and Node declarations cannot authorize routing. Gateway must not run the Linux-only installed compatibility exporter on macOS.
3. Capture initial inputs from authenticated-owner `Paths.sandbox_user_data_dir`: bounded no-follow descriptor traversal of workspace/uploads, reject hardlinks/special files, hash and recheck source identity, atomically publish the existing AgentWorkspaceManifest under `.fleet-agent-inputs/{owner}/{thread}/{reference}`. Offload filesystem work and finish before SQL locks. Existing worker snapshot reader and bound-resume source remain unchanged.
4. Add extension-owned scheduler ticket model/migration and ticket-linked existing reservations; permit nullable attempt_id only with a ticket identity. Existing unreleased-reservation sums continue to count all capacity. Never fabricate an Attempt before run admission. Node claim transfers the same held reservation to its real Attempt, rather than allocating twice. Eligibility must include the full operator compatibility contract: the existing NodeClient already submits WorkerCompatibility to claim_agent, so persist that advertisement under the current Node session and clear it when the session rotates. Tickets compare this current-session contract before charging capacity; heartbeat/allowlist alone cannot prove eligibility. No Runner protocol or image change is needed for this host persistence.
5. Add neutral transactional Scheduler claim callback: under original budget lock acquire parent/occurrence then node/reservation, reserve ticket before queued→launching. No capacity changes neither occurrence nor age/attempt count. Scheduled routing selection is persisted as host-owned JSON via host migration and validated through existing owner API.
6. Add neutral run-admission pre-lock hook before the existing thread advisory/row locks. Scheduled Fleet admission locks parent/occurrence there, validates its launch lease, then delegates original Fleet participant. Insert consumes ticket in the same run/placement transaction. Idempotent reuse consumes replacement ticket against the same original run.
7. Reconcile before generic Scheduler recovery. Unconsumed expiry releases only never-attempted reservations. Consumed/unassigned expiry requires exact occurrence admission key, pending run/no owner or lease, queued placement/no active Attempt and current binding under parent/occurrence→AgentTask→Run→placement→Node→reservation locks. Requeue the same occurrence with original run_id and created_at. Pause/delete/queue timeout terminalizes proven never-attempted retained work atomically, avoiding a permanent thread lock. Once assigned to an Attempt, only original physical STOP releases capacity. Generic Local recovery must not take accepted Fleet ownership.
